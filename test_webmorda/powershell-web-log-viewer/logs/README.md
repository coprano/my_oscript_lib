# Log Files Documentation

This directory contains log files generated by the PowerShell web log viewer application. The log files are in plain text format (`.txt`) and are created by various processes within the application.

## Log File Format

Each log file follows a simple format:

- **Timestamp**: The date and time when the log entry was created.
- **Log Level**: The severity of the log entry (e.g., INFO, WARNING, ERROR).
- **Message**: A descriptive message providing details about the log entry.

### Example Log Entry

```
2023-10-01 12:00:00 INFO Application started successfully.
2023-10-01 12:05:00 WARNING Low disk space on drive C:.
2023-10-01 12:10:00 ERROR Failed to connect to the database.
```

## Accessing Log Files

You can view the contents of the log files through the web interface provided by the PowerShell web server. Simply navigate to the appropriate URL in your web browser to access the logs.

## Log File Generation

Log files are generated automatically by the application based on specific events and actions. Ensure that the application has the necessary permissions to write to the log directory.

For further details on the application and its usage, please refer to the main `README.md` file in the project root.
