# Excel Processor

Python-скрипт, который выполняет JSON-команды для манипуляции с Excel-файлами.

## Возможности

- **Установка текста в ячейку**: Запись текста в определенные ячейки
- **Добавление/удаление строк**: Динамическая вставка или удаление строк
- **Применение тем**: Использование готовых тем или пользовательского стиля
- **Копирование форматов**: Копирование форматирования ячеек между ячейками
- **Отслеживание статуса**: Автоматическая генерация файла статуса
- **Режим отладки**: Детальное логирование выполнения

## Установка

```bash
pip install openpyxl
```

## Использование

### Базовое использование

```bash
# Перезаписать исходный файл
python excel_processor.py --excel-file input.xlsx --json-file commands.json

# Сохранить в новый файл
python excel_processor.py --excel-file input.xlsx --json-file commands.json -o output.xlsx

# Включить вывод отладки
python excel_processor.py --excel-file input.xlsx --json-file commands.json --debug

# Указать пользовательское расположение файла статуса
python excel_processor.py --excel-file input.xlsx --json-file commands.json --status-file /path/to/status.txt

# Использовать пользовательские темы
python excel_processor.py --excel-file input.xlsx --json-file commands.json --presets my_themes.json
```

### Аргументы командной строки

- `--excel-file`: Путь к обрабатываемому Excel-файлу (обязательный)
- `--json-file`: Путь к JSON-файлу, содержащему массив команд (обязательный)
- `-o, --output`: Путь к выходному Excel-файлу (по умолчанию: перезаписывает входной файл)
- `--presets`: Путь к JSON-файлу с пользовательскими темами (опционально)
- `--status-file`: Путь к файлу статуса (по умолчанию: status.txt в директории Excel-файла). Файл статуса **всегда создается**.
- `--debug`: Включить вывод отладки с детальной информацией о выполнении

### Формат JSON-файла

JSON-файл должен содержать **массив** объектов команд:

```json
[
  {
    "command": "set_cell_value",
    "sheet": "Sheet1",
    "row": 1,
    "column": 1,
    "text": "Привет"
  },
  {
    "command": "set_theme",
    "sheet": "Sheet1",
    "row": 1,
    "column": 1,
    "theme": "header"
  }
]
```

### Поведение при выполнении

**Важные характеристики выполнения:**

- Команды выполняются **последовательно** в порядке их появления в JSON-массиве
- Если команда завершается с ошибкой, скрипт **продолжает выполнение** оставшихся команд
- Все ошибки **собираются** и сообщаются вместе в конце
- Файл статуса **всегда создается** (даже при успехе)
- Скрипт проверяет существование входных файлов перед обработкой
- Имена листов проверяются - ошибки сообщаются, если листы не существуют

## Формат JSON-команд

Все команды размещаются в JSON-массиве. Каждый объект команды должен иметь поле `"command"`.

### Установка текста ячейки

Устанавливает значение определенной ячейки.

**Параметры:**
- `sheet` (строка): Имя листа
- `row` (целое число): Номер строки (нумерация с 1)
- `column` (целое число или строка): Номер столбца (нумерация с 1, например 1, 2, 3) или буква столбца (например "A", "B", "C")
- `text` (строка): Текст для установки (опционально, по умолчанию пустая строка)

```json
{
  "command": "set_cell_value",
  "sheet": "Sheet1",
  "row": 1,
  "column": 1,
  "text": "Привет мир"
}
```

### Добавление строки

Вставляет новую пустую строку после указанного номера строки.

**Параметры:**
- `sheet` (строка): Имя листа
- `after_row` (целое число): Вставить новую строку после этой строки

```json
{
  "command": "add_row",
  "sheet": "Sheet1",
  "after_row": 5
}
```

### Удаление строки

Удаляет указанную строку и сдвигает оставшиеся строки вверх.

**Параметры:**
- `sheet` (строка): Имя листа
- `row` (целое число): Номер строки для удаления

```json
{
  "command": "delete_row",
  "sheet": "Sheet1",
  "row": 3
}
```

### Установка темы (готовая)

Применяет предопределенный стиль к ячейке.

**Параметры:**
- `sheet` (строка): Имя листа
- `row` (целое число): Номер строки
- `column` (целое число или строка): Номер столбца (нумерация с 1, например 1, 2, 3) или буква столбца (например "A", "B", "C")
- `theme` (строка): Имя готовой темы

**Доступные темы:** `header`, `title`, `highlight`, `warning`, `success`, `default`

```json
{
  "command": "set_theme",
  "sheet": "Sheet1",
  "row": 1,
  "column": 1,
  "theme": "header"
}
```

### Установка темы (пользовательская)

Применяет пользовательское форматирование к ячейке. Все свойства опциональны.

**Параметры:**
- `sheet` (строка): Имя листа
- `row` (целое число): Номер строки
- `column` (целое число или строка): Номер столбца (нумерация с 1, например 1, 2, 3) или буква столбца (например "A", "B", "C")
- `theme` (объект): Свойства пользовательской темы (см. раздел Свойства пользовательской темы)

```json
{
  "command": "set_theme",
  "sheet": "Sheet1",
  "row": 2,
  "column": 1,
  "theme": {
    "font_name": "Arial",
    "font_size": 12,
    "bold": true,
    "italic": false,
    "underline": false,
    "font_color": "#FF0000",
    "bg_color": "#FFFF00",
    "horizontal": "center",
    "vertical": "center",
    "wrap_text": false,
    "border": {
      "style": "thin",
      "color": "#000000",
      "left": true,
      "right": true,
      "top": true,
      "bottom": true
    }
  }
}
```

### Копирование формата

Копирует все форматирование (шрифт, цвета, границы, выравнивание и т.д.) из одной ячейки в другую. Не копирует значение ячейки.

**Параметры:**
- `source_sheet` (строка): Имя исходного листа
- `source_row` (целое число): Номер исходной строки
- `source_column` (целое число или строка): Номер исходного столбца (нумерация с 1, например 1, 2, 3) или буква столбца (например "A", "B", "C")
- `target_sheet` (строка): Имя целевого листа
- `target_row` (целое число): Номер целевой строки
- `target_column` (целое число или строка): Номер целевого столбца (нумерация с 1, например 1, 2, 3) или буква столбца (например "A", "B", "C")

```json
{
  "command": "copy_format",
  "source_sheet": "Sheet1",
  "source_row": 1,
  "source_column": 1,
  "target_sheet": "Sheet1",
  "target_row": 5,
  "target_column": 1
}
```

## Свойства пользовательской темы

### Свойства шрифта
- `font_name`: Имя семейства шрифта (например "Arial", "Calibri")
- `font_size`: Размер шрифта в пунктах (например 11, 12, 14)
- `bold`: Логическое значение для жирного текста
- `italic`: Логическое значение для курсива
- `underline`: Логическое значение для подчеркнутого текста
- `font_color`: Код цвета в формате hex (например "#FF0000" или "FF0000") - символ `#` опционален

### Фон
- `bg_color` или `background_color`: Код цвета в формате hex для фона ячейки - символ `#` опционален

### Выравнивание
- `horizontal`: "left", "center", "right", "justify"
- `vertical`: "top", "center", "bottom"
- `wrap_text`: Логическое значение для переноса текста

### Границы
- `border.style`: "thin", "medium", "thick", "double", "dotted", "dashed"
- `border.color`: Код цвета в формате hex - символ `#` опционален
- `border.left`, `border.right`, `border.top`, `border.bottom`: Логическое значение для каждой стороны (по умолчанию: true)

## Готовые темы

### Встроенные темы

Скрипт включает следующие встроенные темы:

#### Header (Заголовок)
- Жирный белый текст на синем фоне
- Выравнивание по центру

#### Title (Название)
- Жирный черный текст на светло-синем фоне
- Выравнивание по центру

#### Highlight (Выделение)
- Обычный текст на желтом фоне
- Выравнивание по левому краю

#### Warning (Предупреждение)
- Жирный белый текст на красном фоне
- Выравнивание по центру

#### Success (Успех)
- Белый текст на зеленом фоне
- Выравнивание по центру

#### Default (По умолчанию)
- Обычный черный текст
- Без фона
- Выравнивание по левому краю

### Пользовательские темы

Вы можете определить свои собственные темы в отдельном JSON-файле и загрузить их с помощью аргумента `--presets`.

**Формат файла пользовательских тем (`my_themes.json`):**
```json
{
  "company_header": {
    "font": {
      "name": "Calibri",
      "size": 14,
      "bold": true,
      "color": "#FFFFFF"
    },
    "fill": {
      "color": "#002060"
    },
    "alignment": {
      "horizontal": "center",
      "vertical": "center"
    }
  },
  "subtotal": {
    "font": {
      "name": "Arial",
      "size": 11,
      "bold": true,
      "color": "#000000"
    },
    "fill": {
      "color": "#E7E6E6"
    },
    "alignment": {
      "horizontal": "right",
      "vertical": "center"
    }
  },
  "note": {
    "font": {
      "name": "Arial",
      "size": 9,
      "italic": true,
      "color": "#808080"
    },
    "alignment": {
      "horizontal": "left",
      "vertical": "top",
      "wrap_text": true
    }
  }
}
```

**Использование пользовательских тем:**
```bash
python excel_processor.py --excel-file input.xlsx --json-file commands.json --presets my_themes.json
```

**В вашем JSON с командами:**
```json
{
  "command": "set_theme",
  "sheet": "Sheet1",
  "row": 1,
  "column": 1,
  "theme": "company_header"
}
```

**Свойства пользовательских тем:**
- `font`: Объект с `name`, `size`, `bold`, `italic`, `underline`, `color`
- `fill`: Объект с `color` (hex-код цвета для фона ячейки)
- `alignment`: Объект с `horizontal`, `vertical`, `wrap_text`

Пользовательские темы могут переопределять встроенные темы, используя то же имя. См. `example_presets.json` для полного примера.

## Файл статуса

Скрипт **всегда создает** файл статуса для отслеживания результатов выполнения.

**Формат:**
- **Успех**: Содержит одну строку с `0`
- **Ошибка**: Содержит `1` в первой строке, затем детали ошибок в последующих строках

**Расположение по умолчанию:** `status.txt` в той же директории, что и Excel-файл

**Пользовательское расположение:** Используйте аргумент `--status-file` для указания другого пути

**Пример файла статуса при успехе:**
```
0
```

**Пример файла статуса при ошибке:**
```
1
Error executing command 3 (set_cell_value): Sheet 'InvalidSheet' not found
Command: {"command": "set_cell_value", "sheet": "InvalidSheet", "row": 1, "column": 1, "text": "Hello"}
Error executing command 5 (delete_row): row must be > 0
Command: {"command": "delete_row", "sheet": "Sheet1", "row": 0}
```

## Коды завершения

- `0`: Все команды выполнены успешно
- `1`: Произошла одна или несколько ошибок (см. файл статуса для деталей)

## Обработка ошибок

Скрипт использует подход **продолжения при ошибке**:

1. Команды выполняются последовательно в указанном порядке
2. Если команда завершается с ошибкой, ошибка регистрируется, но выполнение продолжается
3. Все ошибки собираются во время выполнения
4. В конце все ошибки сообщаются вместе
5. Если произошли какие-либо ошибки, скрипт завершается с кодом 1
6. Файл статуса содержит все детали ошибок

Это позволяет увидеть все проблемы сразу, а не исправлять их по одной.

## Обозначение столбцов

Скрипт поддерживает два способа указания столбцов в командах:

1. **Числовое обозначение**: Используйте целые числа (1, 2, 3, ...), где 1 - столбец A, 2 - столбец B и т.д.
2. **Буквенное обозначение**: Используйте буквы столбцов ("A", "B", "C", ..., "Z", "AA", "AB", ...)

Оба обозначения могут использоваться взаимозаменяемо в любой команде, требующей параметр столбца.

**Пример с числовым обозначением:**
```json
{
  "command": "set_cell_value",
  "sheet": "Sheet1",
  "row": 1,
  "column": 1,
  "text": "Столбец A"
}
```

**Пример с буквенным обозначением:**
```json
{
  "command": "set_cell_value",
  "sheet": "Sheet1",
  "row": 1,
  "column": "A",
  "text": "Столбец A"
}
```

Оба примера выше запишут в одну и ту же ячейку (A1).
