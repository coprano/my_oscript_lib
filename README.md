# Excel XML Editor

Инструмент для программного редактирования Excel-файлов через прямую модификацию XML. Сохраняет все изображения, диаграммы, форматирование и другие элементы файла.

## Описание

Excel XML Editor позволяет изменять содержимое ячеек в Excel-файлах без открытия Excel, используя JSON-команды. Инструмент работает напрямую с XML-структурой внутри XLSX-файла, что гарантирует сохранение всех элементов документа.

## Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Подготовка JSON-файла с командами

Создайте JSON-файл с командами для модификации:

```json
[
  {
    "command": "set_cell_value",
    "sheet": "Sheet1",
    "row": 1,
    "column": "A",
    "text": "Привет, мир!"
  },
  {
    "command": "set_cell_value",
    "sheet": "Sheet1",
    "row": 2,
    "column": 3,
    "text": "42"
  }
]
```

### 3. Запуск

```bash
python excel_xml_editor.py --excel-file input.xlsx --json-file commands.json -o output.xlsx
```

## Использование

### Основная команда

```bash
python excel_xml_editor.py --excel-file <входной_файл.xlsx> \
                           --json-file <команды.json> \
                           -o <выходной_файл.xlsx> \
                           [опции]
```

### Параметры командной строки

| Параметр | Обязательный | Описание |
|----------|--------------|----------|
| `--excel-file` | ✓ | Путь к входному Excel-файлу |
| `--json-file` | ✓ | Путь к JSON-файлу с командами |
| `-o, --output-file` | ✓ | Путь к выходному Excel-файлу |
| `--status-file` | | Путь к файлу статуса (по умолчанию: `status.txt` в папке с Excel-файлом) |
| `--no-recalculate` | | Отключить пересчет формул при первом открытии |
| `--full-calc-on-load` | | Установить флаг принудительного пересчета при каждом открытии (не рекомендуется); игнорируется при установке `--no-recalculate`|
| `--debug` | | Включить отладочный вывод |

### Примеры использования

**Базовое использование:**
```bash
python excel_xml_editor.py --excel-file data.xlsx --json-file commands.json -o result.xlsx
```

**С отладочной информацией:**
```bash
python excel_xml_editor.py --excel-file data.xlsx --json-file commands.json -o result.xlsx --debug
```

**Без пересчета формул:**
```bash
python excel_xml_editor.py --excel-file data.xlsx --json-file commands.json -o result.xlsx --no-recalculate
```

**С принудительным пересчетом при каждом открытии:**
```bash
python excel_xml_editor.py --excel-file data.xlsx --json-file commands.json -o result.xlsx --full-calc-on-load
```

## Поддерживаемые команды

### set_cell_value

Устанавливает значение ячейки (текст или число).

```json
{
  "command": "set_cell_value",
  "sheet": "Sheet1",
  "row": 1,
  "column": "A",
  "text": "Значение"
}
```

**Параметры:**
- `sheet` — имя листа (например, "Sheet1")
- `row` — номер строки (нумерация с 1)
- `column` — буква колонки ("A", "B", "C"...) или номер (1, 2, 3...)
- `text` — значение для установки (текст или число)

**Примеры:**
```json
[
  {
    "command": "set_cell_value",
    "sheet": "Sheet1",
    "row": 1,
    "column": "A",
    "text": "Имя сотрудника"
  },
  {
    "command": "set_cell_value",
    "sheet": "Sheet1",
    "row": 2,
    "column": 5,
    "text": "75000"
  },
  {
    "command": "set_cell_value",
    "sheet": "Данные",
    "row": 10,
    "column": "AP",
    "text": "Результат"
  }
]
```

## Технические детали

### Обработка файлов Excel

Excel-файлы (.xlsx) представляют собой ZIP-архивы с XML-файлами внутри. Инструмент:

1. ✅ **Сохраняет:** Все файлы, изображения, диаграммы, форматирование, макросы
2. ✅ **Модифицирует:** Только содержимое ячеек в файлах `xl/worksheets/sheet*.xml`
3. ✅ **Обновляет:** `xl/workbook.xml` для настройки пересчета формул
4. ❌ **Удаляет:** `xl/calcChain.xml` (см. ниже)

### Пересчет формул

#### По умолчанию (рекомендуется)

При модификации ячеек с данными формулы, зависящие от этих ячеек, должны быть пересчитаны. Инструмент использует следующую стратегию:

1. **Удаляет `xl/calcChain.xml`** — этот файл содержит цепочку вычислений (порядок пересчета формул). После внешней модификации ячеек эта цепочка становится неактуальной.

2. **Устанавливает `calcMode="auto"`** в `xl/workbook.xml` — указывает Excel использовать автоматический режим вычислений.

3. **При первом открытии файла:** Excel обнаруживает отсутствие calcChain.xml, пересчитывает все формулы и создает новый файл цепочки вычислений. Однако, если файл перед закрытием не сохранять, будет продолжать пересчитывать при каждом открытии.

#### Флаг `--full-calc-on-load`

Устанавливает дополнительный атрибут `fullCalcOnLoad="1"` в workbook.xml. 

**⚠️ Внимание:** В теории Excel должен удалить этот флаг после первого открытия, но в некоторых версиях флаг сохраняется, что приводит к пересчету формул при каждом открытии файла (снижение производительности).

**Рекомендация:** Используйте только если поведение по умолчанию не работает в вашей версии Excel.

#### Флаг `--no-recalculate`

Полностью отключает пересчет формул:
- Не удаляет calcChain.xml
- Не модифицирует настройки вычислений в workbook.xml
- Формулы останутся с прежними значениями

### Файлы, удаляемые при обработке

| Файл | Причина удаления | Последствия |
|------|------------------|-------------|
| `xl/calcChain.xml` | Цепочка вычислений устарела после изменения ячеек | Excel пересоздаст файл при первом открытии с актуальной цепочкой |

### Типы данных ячеек

Инструмент автоматически определяет тип данных:

- **Число:** Если значение можно преобразовать в число, ячейка получит тип `t="n"` с элементом `<v>`
- **Текст:** Все остальные значения сохраняются как `t="inlineStr"` с элементом `<is><t>`
- **Пустая ячейка:** Создается без типа и содержимого

### Экранирование XML

Все специальные символы XML автоматически экранируются:
- `&` → `&amp;`
- `<` → `&lt;`
- `>` → `&gt;`
- `"` → `&quot;`
- `'` → `&apos;`
- Перевод строки → `&#10;`
- Возврат каретки → `&#13;`
- Табуляция → `&#9;`

## Файл статуса

После выполнения создается файл статуса (по умолчанию `status.txt`) с результатом операции:

**При успехе:**
```
SUCCESS
```

**При ошибке:**
```
FAILED: Описание ошибки
```

Путь к файлу статуса можно указать через параметр `--status-file`.

- Python 3.6+

## Примеры команд

См. файл `example_commands.json` для полного набора примеров.

## Ограничения

- Поддерживается только команда `set_cell_value`
- Работает только с форматом XLSX (не XLS)
- Не поддерживается изменение форматирования (используйте другие инструменты)
- Не поддерживается добавление/удаление листов

## Поддержка

При возникновении проблем:
1. Проверьте формат JSON-файла (должен быть валидным JSON)
2. Используйте флаг `--debug` для получения детальной информации
3. Проверьте файл статуса для получения информации об ошибках
4. Убедитесь, что входной Excel-файл не поврежден
